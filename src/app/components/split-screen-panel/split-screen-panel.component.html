HOW SPLIT-SCREEN WORKS HERE

  1. 1. Copy the link from the header and send it to a friend — they don't need an account to preview.
  2. 2. When the friend opens S.M.U.V.E. with the link, their browser joins your split-screen room instantly.
  3. 3. Each of you runs the same game on your own device. The HUDs mirror your scores and current turn in real time.
  4. 4. Voice chat rides the existing WebRTC relay (voice_signal) — no plugin to install.

We can't reach inside third-party game sources (gamepix, retrogames, etc.) on Android, so each device shows the full cabinet UI locally and we sync gameplay metadata only. S.M.U.V.E.-native game builds (WASM / internal cabinets) get the synchronized HUD.
